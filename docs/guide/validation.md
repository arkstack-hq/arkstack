# Validation

Arkstack uses [Kanun](https://arkstack-hq.github.io/kanun/) for request and domain validation. Full templates include Kanun and expose a controller helper for the common request-validation path.

## Validate In A Controller

Controllers generated by Arkstack extend `BaseController`. Call `this.validate()` with Kanun rules to validate the current request body and receive the validated data:

```ts
export default class UserController extends BaseController {
  async create() {
    const data = await this.validate({
      name: 'required|string|min:2',
      email: 'required|email',
      age: 'numeric|min:18',
    });

    const user = await User.query().create(data);

    return new UserResource(user).response().setStatusCode(201);
  }
}
```

The helper calls `Validator.make(this.body, rules).validate()` internally. Validation failures throw Kanun's `ValidationException` and flow through Arkstack's normal error handling.

## Validate Anywhere

Use `Validator` directly in services, commands, jobs, or inline routes:

```ts
import { Validator } from 'kanun';

const data = await Validator.make(input, {
  email: 'required|email',
  role: 'required|in:admin,member',
}).validate();
```

Use `passes()` or `fails()` when validation should branch instead of throwing:

```ts
const validator = Validator.make(input, {
  email: 'required|email',
});

if (await validator.fails()) {
  return validator.errors().all();
}
```

## Browser Validation

Importing `@arkstack/http/setup` connects Kanun failures to the active Arkstack session. Routes using the `web` middleware redirect back, flash validation errors, and retain submitted input through `old()`.

See [Validation Errors](/guide/http#validation-errors) for the Arkstack session and redirect workflow.
